# Archivo

Historial de auditorías, revisiones, planes y reportes anteriores. Son documentos **históricos**: describen el estado del
proyecto en su momento y pueden no coincidir con el código actual. Se conservan solo como registro de cambios; la
documentación vigente está en el [`README.md`](../README.md) de la raíz y en [`deploy/README.md`](../deploy/README.md).

| Documento | Qué es |
|---|---|
| `AUDITORIA_APP.md` | Auditoría de las 155 pantallas de la app móvil contra los 17 servicios (1-oct-2026): P0/P1/P2, revisión de seguridad y UX |
| `navigation_audit.md` | Auditoría de navegación de la app |
| `auditoria_backend_vs_mobile.md` | Cruce de endpoints del backend contra lo que consume la app |
| `analisis_backend_veterinario.md`, `analisis_flujos.md`, `analisis_paridad_completo.md` | Análisis de flujos y paridad entre backend y frontend |
| `estado_backend_vs_frontend.md`, `resumen_verificacion_completa.md`, `verificacion_completa_sistema.md` | Estados y verificaciones del sistema |
| `backend_integration_plan.md`, `plan_homologacion_modelos.md`, `plan_tablas_supabase.md` | Planes de integración, homologación de modelos y tablas |
| `michicondrias_ai_context.md`, `PROJECT.md`, `progress.md` | Contexto y notas de proyecto de etapas anteriores |
| `endpoint_smoke_test_report.json`, `tmp_analyze.py` | Reporte de pruebas de endpoints (cuando corría en AWS Lambda) y script temporal |
